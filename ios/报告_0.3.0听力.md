## 拍了什么板

- 做进一叶笺，不另开 app：免费签名最多 3 个侧载 app；一叶笺本来就是「上面播放、下面文字」，也已经有通大管家的 iCloud 管子。
- 录屏抽声音不做：录屏会混进别的声音，从 Claude 的朗读里抽也不干净；大管家直接配音更干净、全自动。
- 播放列表照 Song 说的：默认只有声音，字要点「文」才出来；每篇几遍、放够自动下一篇。
- 收件：大管家往 `_大管家/送来/` 放 json + 录音（接口 v1 新加「送来」一节，字段、切句规矩、文件名都写死了，两头照着做）。
- 每句表（第几秒开始）跟着录音存一份 `.marks.json`，镜像、导入时一起走。
- 后台播放：Info.plist 加了 `UIBackgroundModes: audio`（免费签名能用，不是付费能力）。
