# 一叶笺 iPhone 版：第一次装（照着点就行）

用 SideStore 免费签名装：不花钱，7 天要续一次（下面设好快捷指令就每天自己续）。手机菜单按英文写。

要准备：一台 Windows 电脑（64 位）、一根数据线、你的 Apple ID、手机设了锁屏密码。

## 一、电脑上（一次，大约 15 分钟）

1. **装 iTunes**：用 Apple 官网的 64 位版 <https://www.apple.com/itunes/download/win64>，一路下一步。Microsoft Store 里那个有人装不上，别用。装完不用打开。
2. **装 iloader**：打开 <https://github.com/nab138/iloader/releases>，下最新版里的 `iloader-windows-x64.msi`，一路 Next，最后 Finish（「Launch iloader」勾着）。只认这个地址和 iloader.app，别处下的不要。
3. **插手机**：数据线连电脑。手机弹 **Trust This Computer?** → 点 **Trust** → 输锁屏密码。
4. **iloader 登 Apple ID**：左上角填 Apple ID 和密码 → **Login**。手机上弹登录请求 → **Allow**（写着 MacBook Pro 没关系）→ 把手机上显示的验证码填进 iloader → **Submit**，等到「Logged in successfully!」。
5. **装 SideStore**：iloader 右上角点你手机的名字（没看到就点 **Refresh**）。手机上再弹 Trust 就再点一次、输密码。手机名字变蓝以后，点右下角 **SideStore (Stable)**，等到「SideStore Installed!」。拔线，电脑这头就完了。

## 二、手机上（一次，大约 5 分钟）

6. **开发者模式**：Settings > Privacy & Security > 拉到最底下 **Developer Mode** → 打开 → **Restart**。重启后弹窗点 **Turn On**（或 Enable），输密码。
7. **信任证书**：Settings > General > **VPN & Device Management** → 点 Developer App 下面你的 Apple ID → **Trust** → 再点一次 **Trust**（或 Allow）。
8. **装 LocalDevVPN**（SideStore 在手机上续签要它）：App Store 搜 **LocalDevVPN**，装上，打开点 **Connect**；问要不要加 VPN 配置点 **Allow**，输密码。屏幕顶上出现 VPN 就好了。它只在手机里自己连自己，不走流量，可以一直开着。
9. **登 SideStore**：打开 SideStore，问本地网络、通知都点 **Allow**。底下 **Settings** → **Sign in with Apple ID**，登同一个 Apple ID（验证码跟第 4 步一样）。
10. **加一叶笺的源**：SideStore 底下 **Sources** → 右上角 **+** → 粘贴下面这行 → **Add**：

    ```
    https://qianshoulab.github.io/qianye/ios/sidestore.json
    ```

11. **装一叶笺**：**Browse** 里点 **Yiye** → **FREE**（或 Install）。装好桌面上叫 **Yiye**（手机是英文所以显示英文名；app 设置里切成中文，界面就是「一叶笺」）。

## 三、第一次打开一叶笺

12. 列表顶上问「每条笔记在 iCloud 云盘也存一份」→ 点 **Choose folder**，文件面板开在 iCloud Drive 那一层，直接点右上角 **Open**。app 自己在里面建「一叶笺」文件夹。想放别处也行，挑哪个用哪个；设置里能换。
    - 手机得先开 iCloud Drive：Settings > 你的名字 > iCloud > **iCloud Drive** 打开。
13. 拍照认字第一次会问相机权限 → **Allow**；保存相册第一次问照片权限 → **Allow**。

## 四、掌机上（让大管家能接活）

14. 掌机装 **iCloud for Windows**（Microsoft Store 或 Apple 官网都行），登同一个 Apple ID，勾上 **iCloud Drive**。手机上的「一叶笺」文件夹会出现在 `%USERPROFILE%\iCloudDrive\一叶笺`。大管家那头怎么接是另一张单（057）的事。没装好之前，一叶笺照常放请求，顶上显示「大管家没来」，装好了它自己接着理。

## 五、以后

- **有新版**：不用你发版，施工队改了版本号、CI 全过，GitHub 自己发。SideStore → **My Apps** → Yiye 旁边出 **Update**，点一下（LocalDevVPN 开着）。
- **7 天一续**：设了下面的快捷指令就不用管。手动续：开 LocalDevVPN → SideStore → **My Apps** → **Refresh All**。过了 7 天没续，app 打不开，数据不丢，续上照常用。
- 免费 Apple ID 同时最多 3 个侧载 app（SideStore 自己算一个），一周最多装 10 次（重装也算）。

## 六、每天自动续签（快捷指令，一次设好）

1. 打开 **Shortcuts** → 底下 **Automation** → 右上角 **+** → **Time of Day**。
2. 选 **3:00 AM**、**Daily**；下面选 **Run Immediately**（不要 Run After Confirmation），**Notify When Run** 关掉 → **Next**。
3. **New Blank Automation** → **Add Action** → 搜 **SideStore** → 选 **Refresh All Apps** → **Done**。
4. 续签要 LocalDevVPN 连着。最省事：让它一直连着。想只在续签时连：在第 3 步那个动作前面再加一个 **Set VPN**（选 LocalDevVPN、Connect），加不上就还是让它一直连着。
5. 第一次手动跑一下：在快捷指令里点这个自动化旁边的运行，问权限都点 **Allow**。

## 七、侧键一按就录（0.2.0 起，设一次）

1. Settings > **Action Button**，左右滑到 **Shortcut**。
2. 点 **Choose a Shortcut**，找到 **Yiye**，选 **Record a voice note**（手机是中文就叫「录一段」）。
3. 以后按一下侧键：一叶笺直接打开在录音页，已经在录，说就行；说完点「说完了」。手机锁着要先 Face ID 解锁。
4. 第一次录会问话筒、语音识别两个权限，都点 **Allow**。第一次转字要联网下一个苹果的语音模型，下完以后不用网。

## 出问题

- iloader 报错：它下面会给建议；照着做还不行，把整段报错发给聊天窗口。
- 手机升级系统以后 SideStore 续不了：多半是配对文件过期，插电脑用 iloader 再装一次 SideStore（数据不丢）。
- 以后买了开发者会员换正式版：Bundle ID 会变，数据不会自己过去。新版里 设置 > 镜像文件夹 选同一个文件夹 → **Import from folder**，一条不落搬回来。
