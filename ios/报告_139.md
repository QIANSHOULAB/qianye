喊一声就接通大管家（一叶笺 0.7.22）：Siri 说「叫大管家」（英文 Siri 说「Call Yiye」），嘟一声接通，说完它就听、带搜索答；说「挂掉」「拜拜」「好，挂了」就挂，嘟嘟两声，别家的歌自己接着放。
挂断词手机自己认，不过信箱：信箱断了、电脑关着也挂得掉。电话里还能问「书童做完没」、说「派个活：……」（说「对」才发）、开关电脑软件（138）。
锁屏能不能直接接通：代码做了（先在后台开话筒，系统不让再请你解锁），模拟器验不了，要你真机试一下——第 3 步就是。

# 139 报告：一叶笺打电话式

电脑自动工 139（Opus · 高），11-25 12:01 认领；按单子先做了 144（0.7.21 已发）。接口 **v3.13**（`ios/docs/大管家接口.md` 第一大节）。一叶笺 **0.7.22**。

## 锁屏能不能接通（结论）

- **能试的路都接上了，真机还没验。** iOS 26 SDK 里查过（CI 上 grep SDK，结果在 `ios/shots/probe/sdk.txt`）：
  - `AudioRecordingIntent`（iOS 18 起）在：「叫大管家」做成了它，`supportedModes = [.background, .foreground(.dynamic)]`——锁着屏先在后台直接开话筒；系统不让（3 秒内话筒没起来）就 `continueInForeground` 请你解锁（看一眼 Face ID），解锁后接着接通。
  - Live Activity（锁屏、灵动岛上的小条）要 Widget 扩展：免费签名只能装 3 个（SideStore、一叶笺、YiyeLive），没加。苹果的说法是开录音的意图最好配一个 Live Activity，没有它系统会不会掐话筒，只有真机知道。
  - CallKit（当一通电话打）没走：要先起一通通话再开话筒，从意图里起照样卡在锁屏开话筒这一步；大陆的 App Store 也不收带 CallKit 的 App，侧载能不能用没验。
- **真机要是锁屏喊了它让你解锁**：那就是系统不让后台开话筒。骑车时手机放车把上、屏幕亮着（或者先解锁再揣兜）就行；「答完 60 秒没话自己挂」这时候不会开（下面说为什么）。
- **答完 60 秒没话自己挂**：只有手机记下「锁着屏接通过一次」才开（锁屏喊得回来，才敢自己挂）。陪玩（打游戏）里永远不自己挂。

## 做了啥

**手机（`YiyeKit/Call139.swift`、`Yiye/Store/Companion.swift` 打电话式那节、`Yiye/Store/ClipReader.swift`、`Yiye/App/Intents.swift`）**

- 「叫大管家」意图（`CallButlerIntent`），配进 App Shortcuts：英文 `Call Yiye` / `Call the butler in Yiye` / `Talk to Yiye`，中文 `叫大管家` / `用一叶笺叫大管家` / `打给大管家`。Info.plist 加 `INAlternativeAppNames`：「大管家」「Yiye」「Butler」也当 App 名字认（英文 Siri 念不出「一叶笺」）。捷径、侧键（Action Button）、耳机上喊 Siri 都走它。
- 接通「嘟」一声，就是深聊那套：停 1.5 秒自动发，大管家 Opus 带搜索答。顶上一条小胶囊：在听 / 在听你说 / 在想 / 在说 + 红色挂断键。
- 陪玩开着时叫：陪玩里转深聊，声音照陪玩（混着、压低）；没开：一只电话耳朵——会话不带 `mixWithOthers`（别家的歌停，跟打电话一样），蓝牙耳机用耳机的麦（AirPods 高音质收音 `bluetoothHighQualityRecording`，不支持的耳机退到 HFP）。
- 挂断词手机本地认：3.5 秒以内的一句先用 iOS 26 SpeechTranscriber（中文，本机认、不上传）认字，整句是挂断词就挂，**这句不寄**。挂断词：挂掉、挂了、挂吧、挂断、拜拜、再见、bye，前后带嗯 / 好 / 那 / 行 / 先也算；电话里「不聊了 / 结束 / 退出」也算挂。「把那个会话挂掉」「挂个后台」不算，照常交大管家。117 的声纹建好了先问一句是不是你（2 秒没回当是你，信箱断了也挂得掉）。
- 挂：嘟嘟两声、话筒马上不听、嘟完停引擎、`setActive(false, .notifyOthersOnDeactivation)`——Apple Music、Spotify 收到这个就自己接着放。陪玩开着时说挂断词：整个陪玩都停（直播还开着也不再自己接着听）。
- 挂的时候还在等的回答（大管家回过「收到」的）不扔：到了存进「深聊」文件夹，下次接通先念一句「上回挂了以后答好了：……」。
- 中文模型第一次要下：接通时后台下，这一通先照旧交大管家认（大管家那头兜底，见下）。
- 秒数：每通电话「说完到第一声」「说挂掉到挂断」记在工具箱「陪玩」下面一行。

**大管家（pc-butler main 184a949，已装电脑；`handheld/deep.py`、`phone.py`、`progress.py`、`prompts/deep_gate.md`）**

- 挂断词兜底：手机没认出来、交上来的整句挂断词，回 `end`，手机照挂。
- 问进度：「现在在干啥」「书童做完没」「今天做完几张」「有没有卡着等我的」本地认，认不出的门多一类 `progress`。先回「收到」，再读 orders（掌机、电脑、待派）、报告、各仓库最近的提交（钥匙类整段扔掉），一个一档的一次性大脑两三句答，配好音回来；不碰你深聊话题的大脑。
- 派活：「派个活：……」→「要我派：……，对吗？」→ 说「对」进 orders `待派/`（写明手机电话里派的），派单员分；「不对，……」照改的再复述；「算了」不派；20 秒没回（你挂了）不发，进 orders `等确认/`。跟陪玩派活同一套。

## 我替你定了这些

- 中文说法用「叫大管家」：靠给 App 加了个别名「大管家」凑出来的（Siri 的说法里必须带 App 名）。英文 Siri 说「Call Yiye」；「Call」开头可能被当成打电话给联系人，那就说「Talk to Yiye」。
- 挂断词只认 3.5 秒以内的短句（长句交大管家）；整句才挂。
- 「答完 60 秒自己挂」靠手机自己判断锁屏喊不喊得回来：锁着屏接通成功过一次才开，不用你设。
- 陪玩开着时叫大管家：转陪玩的深聊，声音不换（歌照旧压低不停）；在这通里说挂断词，整个陪玩停。
- 进度的回答用一档（快），不动你深聊那个四档的话题大脑。
- 锁屏上没有小条（要扩展，装不下）。
