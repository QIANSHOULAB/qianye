# 222 听力原文页：跟着放开关、点一下出词义、点两下出整句意思（0.7.38，build 39，11-27）

- 原文页点一下选一个词、点两下整句，卡片给中文（iOS 自带 Translation，只在手机上翻）；卡片上「难词」「已掌握」「从这句放」「单句循环」。底下多「跟着放」开关；原来点一下跳句挪进卡片。长按拖选照旧。
- 代码：`Yiye/UI/ListenWords.swift`（翻译、卡片、能点词的文字视图）、`ListenViews.swift` 的 `TextSheet`、YiyeKit `WordPick222.swift`（切词、认点两下、停滚规则，单测）、UI 测试 `ListenTextTests`；截图画面多 `listen-word`、`listen-line`。
- 坑：YiyeKit 里用 `CGRect.minX` 要 `import CoreGraphics`（macOS 单测过、iOS 编不过）；点两下时系统会抢先选一个词，要先认「两下」再看有没有选中；系统翻译在模拟器里不能用（测试走假翻译）；build 那趟 job 上限 75 分钟、实测 64 分钟上下，快顶到了；失败后「原样重跑」会在截图提交那步撞车，要 `gh workflow run iOS --ref main` 重起。
