## 第 1 轮（CI e792a61，11-20 10:42）

| 哪儿 | 输在哪 | 怎么改 |
|---|---|---|
| 写字页 | 横线 32pt 一条，字行只有 28pt，越往下字越压线（第 4 行字已经压在线上） | 量出来行高 = 32 − 4，4 正好是 baselineOffset。TextKit 2 里 baselineOffset 会吃掉固定行高。去掉 baselineOffset，字贴行底，正好坐在横线上（信纸本来就这样） |
| 分享页 | 底下两个版式缩略图左边被裁（「月3日交接」） | 缩略图按宽放、从上往下裁 |
| 拍照认字 | Vision 把「A线早班」当成 A、B、C 编号的清单，又把编号拼回字里：「A A线早班」「1. 1.螺丝」 | 编号本来就在字里的照原样；圆点、短横换成 `- ` |
| 拍照认字 | 勾选框 □ 认成汉字「口」 | 连着两行以上开头是「口 / □ / ☐」，当勾选框，变成 `- ` 列表 |
| 拍照认字 | 标黄几乎不起作用：10 张图 63 个错字只标中 2 个（Vision 每行的信心都给得很高，候选也一样） | 认两遍对答案（跟网页版一样）：RecognizeDocumentsRequest 一遍，RecognizeTextRequest 不开语言校正再一遍，同一位置的行两遍不一样的字标黄 |
| 分享图（英文） | 「new blade on #3」被当成「名字＋数字」，3 跑到右边那一列 | 「#3」「No. 5」「第3」是编号；「Nov 18」是日期；带逗号的长句子末尾的数也不算 |
| 列表、写字页 | 时间是截图机器的 UTC | 截图按新加坡时间跑 |
| 列表 | 原木桌面、灰白纸条、左上角回形针、置顶的米黄纸，跟少数派 2014 的描述对得上 | 不动 |
| 顶栏、按钮 | 圆角小方块、上亮下暗一圈细边，没有液态玻璃（UIDesignRequiresCompatibility + 自己画） | 不动 |
| 分享图「便签」 | 跟网页版一叶笺「便签」一致（暖白纸、细噪点、橙红点缀、落款前一道线）；跟锤子分享图比少了纸边两道框线、桌面衬底 | 单子定的是网页版「便签」原样，先不加；Song 看了想要锤子那两道框线再加 |

## 第 2 轮（CI 23d7988，11-20 11:04）

| 哪儿 | 结果 | 下一步 |
|---|---|---|
| 写字页 | 字行 32pt 一行，跟横线对齐了（2 倍图量：字行间隔 64px，横线间隔 64px，字底离线 2.5pt），标题、列表、引用、居中每一行都坐在线上 | 不动 |
| 分享页 | 两个缩略图整宽显示了 | 不动 |
| 拍照认字 | 清单编号不再重复（p3 92%→100%，h2 76%→100%）；英文首行「Shift report, Nov 18」成了标题；印刷 95%→97%，手写 83%→89% | — |
| 标黄 | 第二遍 RecognizeTextRequest 认出来的跟第一遍一模一样（同一个引擎），对答案对不出东西。但每行的信心有用：错的行 0.37–0.87，对的行 0.78–0.99 | 改按每行信心标：低于 0.82 的行标黄；Vision 给了逐词信心的，只标低的那几个词 |
| 勾选框 | 没变成列表：Vision 把每一行切成单独一段，块里判断「连着两行」不成立 | 改成整页认完以后按行判断 |
| 时间 | 新加坡时间了 | 不动 |

## 第 3 轮（CI f882171，11-20 11:18）

| 哪儿 | 结果 | 下一步 |
|---|---|---|
| 标黄 | 按每行信心标以后：10 张样张标黄 11 段，11 段都真有错；认错的 42 个字里 20 个落在黄底里。Vision 对中文不给逐词结果，只能整行标 | 第二遍认字没用，去掉（每张省 0.6–1.3 秒） |
| 勾选框 | 「口牛奶2盒」变成「- 牛奶2盒」，p2 认对 81%→100%；印刷合计 99% | 不动 |
| 截图「拍照认字结果」 | 用的是印刷体样图，信心都高，看不到标黄 | 换成手写的样图（中文龙藏体、英文 Patrick Hand），截图里能看到标黄 |
| 样张报告 | 「标黄里真错」把少个空格也算成错（认对几成不算空格，两边不一致） | 空格多少一律不算错 |
