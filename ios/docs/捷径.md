# 「存进一叶笺」捷径怎么搭（给 Song，iPhone 英文界面）

搭一次，以后在任何 app 的分享菜单里都能把网页存进一叶笺。要装 0.7.10 以上。

> 先说实话：这份是照 iOS 快捷指令（Shortcuts）的菜单写的，CI 的模拟器里没有「快捷指令」app，我没法在模拟器里照着搭一遍、截图；每一步下面写的「看到什么算对」是照 App Intents 的做法推的，第一次搭请你对一对，哪步对不上告诉我，我改这份。

## 搭一个存网页的（主要用法：Safari、新闻 app 里点分享）

1. 打开 **Shortcuts** → 右上角 **+**。
   - 对了：出现一个空白的新快捷指令，上面有 **Add Action**。
2. 点 **Add Action**，搜索框里输入 `Yiye`，在结果里点 **Save to Yiye**（图标是向下的箭头进盒子）。
   - 对了：画面上出现一行动作，写着「Save to Yiye」，后面有两个蓝色的格子 **URL** 和 **Text**（没填的时候显示灰字）。
3. 点 **URL** 格子，键盘上方的一排里点 **Shortcut Input**。
   - 对了：URL 格子变成一个蓝色的药丸，写着「Shortcut Input」。**Text** 格子不要动，留空。
4. 点最上面的名字（或者右下角的 **ⓘ**），把名字改成 `Save to Yiye`。
5. 点 **ⓘ**（Details）→ 打开 **Show in Share Sheet**。
   - 对了：下面多出一行 **Share Sheet Types**（写着 Any 之类）。点开它，先把全部取消，只留下 **URLs**、**Safari web pages**（要是列表里有 **Articles** 也留着）。
6. 点右上角 **Done**。
   - 对了：快捷指令列表里多了一块「Save to Yiye」。

## 用

1. Safari（或者别的 app）打开一篇文章 → 点分享（方框加向上箭头）。
2. 分享菜单往下划，找 **Save to Yiye**；没看到就划到最底下点 **Edit Actions…**，把 Save to Yiye 加进「Favorites」。
   - 对了：点一下，顶上弹出一句「存好了，大管家在扒正文。」（大管家没接上时是「存好了。大管家还没接上，正文先不扒。」）。
3. 打开一叶笺：多了一条文章便签，第一行是网页标题，最后一行是网址；过几秒到几十秒，正文换成大管家扒好的干净版。
4. 点开这条，底下有两个按钮：**直接配音**（照原文念，进小耳机）、**简写**（大管家写成一到三篇英文听力稿，配好音进小耳机，写好了栏上变成「简写好了，点这里去听」）。

## 想把分享来的一段文字也存起来

再搭一个，做法同上，只有两处不一样：第 3 步点的是 **Text** 格子（URL 格子留空）；第 5 步 Share Sheet Types 只留 **Text**。名字叫 `Save text to Yiye`。文字存成普通便签，不扒正文。
