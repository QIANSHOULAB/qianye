## 做了什么
1. **听力只住小耳机**（`kind == "listen"`，配没配上音都算）：便签主页、各文件夹、搜索、文件夹面板的计数（含「全部便签」）、「挪到文件夹」菜单（列表批量的、写字页的）都过滤掉；只装听力的文件夹（里面有便签、每一条都是听力）在文件夹面板和两个挪动菜单里都不列，空文件夹照旧列；之前选中过这种文件夹的，主页当「全部」看。小耳机（`PlaylistScreen`）收全：`kind == "listen"` 的不管 `inListen` 是不是 true 都在，加上 Song 自己点小耳机放进来的普通便签（两边都在，送去配音照旧）。规则在 YiyeKit `Listen112.swift` 的 `ListenRule`。
2. **没配上音的挂「重配」**：没录音、也没在等配音的那条，在小耳机当天那组里挂「重配」按钮（走现有的 `requestDub`），点一行本身还是让手机先念。
3. **听完自己清**：`Note.heardAt` = 第一次完整放完一遍的时间（`AudioPlayback.finishedOnce`，小耳机里、写字页里放完都算，只记第一次）。听力听完满 7 天 → `AppModel.cleanHeard()` → 进 111 的废纸篓（再留 3 天能放回；不弹提示）。没听完的一直留着；普通便签一条都不自动清；打开 app、回到前台时跑，不加后台任务。从废纸篓放回的，听完过的从放回那天重新算 7 天。听完的那条在小耳机里淡一点，不加字。
4. **整串循环**：播放条上「几遍」那排右边一个循环图标（`repeat`），开着高亮，不加字；最后一条放完（该放的遍数也放够了）回到这一串第一条接着放，只有一条就接着放这条。记在 `settings.listenLoopAll`（默认关），锁屏、控制中心的上一首下一首不受影响。
5. **小耳机里标词**：`TextSheet`（点「文」出来的原文）一句改成一个只读、能选词的文字视图（`SentenceText`）；选中一个词或词组，系统菜单最前面多「已掌握」「难词」（英文 Known / Hard word），走现成的 `AppModel.markWord`（大管家收到改 `词表.md`，没动格式，仍是 known / learning）。点一句跳到那句接着放，照旧；已经选着词时点一下只是收掉菜单、不跳句。写字页那边菜单的字也换成同样的两个。
6. 镜像导入（`mergeImported`）建的 `kind == "listen"` 笔记顺手把 `inListen` 设上。

## 二、今天（11-24）的简讯为什么在便签主页、不在小耳机当天那组

**我能确定的（读代码）**：
- 大管家送稿的两条路（信箱、iCloud「送来」），手机都走 `AppModel.addDelivery`，`kind` 取自信里的 `kind`（大管家 `tingli.py` 写死 `"listen"`），并且 0.6.0（11-23 16:51）起一律 `inListen = true`。所以 0.6.0 及以后的版本，信箱 / 送来这两条路送到的简讯是进小耳机的。
- 会让 `kind == "listen"` 的笔记不在小耳机的只有三条：(a) 0.6.0 之前的版本（0.4.1 起「大管家送来的不再自己进听力」，要点了小耳机才进）；(b) 从镜像文件夹导入（`Capture.swift` 的 `mergeImported`）建的笔记，从来不设 `inListen`（这条是真漏洞，已修，并且现在小耳机不看 `inListen` 了）；(c) `backfillListen` 只补了装 0.6.0 那一次、而且只补有录音的。
- 便签主页过去不过滤 `kind`，所以不管哪条路，简讯一直都显示在便签主页——你看到的「出现在便签页面里」是这个原因。日期分组按笔记的 `createdAt` 算，信里的 `at` 是新加坡时区，分组没有算错天的地方。

**我不能确定的**：你手机上 11-24 早上那一批具体走了哪条路。我在这台电脑上看不到手机（也没有手机的日志），所以说不出是 (a) 还是 (b)。最可能是 (a)：你手机上跑的要是 0.6.0 之前的版本，就符合「简讯没进小耳机、只在便签页」。要确认的话：设置页最底下看版本号。

**修的方式**：不再靠 `inListen` 这个会漏的标记，小耳机直接认 `kind == "listen"`，便签主页直接过滤 `kind == "listen"`。以后不管哪条路来的听力，都在小耳机、不在便签，没有「两边都看不到」的（单测 `testNoNoteIsInNeitherPlace` 把每种 kind × inListen 的组合都跑了一遍）。

大管家那头没动、没发现要改的：`tingli.py` 送出去的信里 `kind` 一直是 `listen`，没带录音的（081 允许）手机也收，在小耳机里就是「等配音」那一条。
