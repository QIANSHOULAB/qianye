## 从参照里定下的五条（字体、留白、行距、对齐、颜色）
1. **字体**：标题和正文一种无衬线（苹方 / 思源黑体），只有「信笺」「杂志」用衬线（思源宋体）。数字跟正文同一种字，靠对齐整齐，不换等宽字体。
2. **留白**：左右边距不小于宽度的 7%（390 宽的图 28 以上）；标题下空一行半；分组之间空一行。
3. **行距**：正文 1.6～1.75 倍；「名字＋数字」的行 1.9 倍以上（数的时候眼睛要横着走）。
4. **对齐**：名字靠左，数字小数点对齐，单位跟在数后面、左对齐；序号右对齐，折行缩进到正文开头。
5. **颜色**：正文深灰不用纯黑；全图只许一个强调色（标题记号、序号、分组标题用它）；说明、日期浅灰。
