# 誊抄僧 · 设计记录

## 毛坯（2026-11-01～02，v0.1.0，施工单 012）

Song 的原话：「手写字拍照生成图片，打字复制的内容生成图片文字……识别错了可以修改，有点像以前的锤子便签，但比他多的功能是许多排版可选、能识别标题。」「锤子便签的标准是最低要求。」「代码是最简单的，难在设计和简洁的美学，和对使用者痛点的理解。」

开工先写了 `docs/痛点.md`（被组长催着报数、要发一条通知、列个清单三个时刻），又收了 7 张简洁路线的获奖作品当参照（`docs/参照/来源.md`），定下字体、留白、行距、对齐、颜色五条。

### 拍的板
- **名字**：誊抄僧，副标题照单子先用「施主乱写，贫僧誊抄」。
- **一屏到底，不分页**：写字框 → 预览 → 版式缩略图 → 比例、格式 → 底下一条「分享」。打开就是写字框；不选版式也能分享。打字到发出去 1 下，拍照到发出去 2 下（拍、分享）。
- **改字就在写字框里改**：textarea 底下垫一层一模一样的「镜像」，把拿不准的字涂黄；点到黄字上，那几个字自动选中，直接打字就替换了。不另开一页「核对」。改过的字自动不再标黄。
- **标题认错了点预览**：点哪一行哪一行当标题，点标题就不要标题。比在设置里选强。
- **排版和出图是同一套 canvas 代码**：预览看到什么，分享出去就是什么。图宽 390（逻辑像素），按 3 倍画（1170 宽）。字用系统的苹方 / 思源黑体；只有信笺、杂志用思源宋体（Google Fonts，用到才下，按字切片下）。
- **认结构**（`parse()`）：标题（第一行短、不以句号逗号结尾；第一行是日期就用第二行）；「名字＋数字」（名字靠左，数字小数点对齐，单位小一号跟后面，合计行加粗加细线）；清单（1. 1、 (1) ① • - □，序号右对齐，折行缩进）；「时间：xx」键值（冒号对齐）；连着 3 行以上「周一 张师傅」这种两列也对齐；正文开头的「各车间：」当称呼；最后一两行短字（部门、日期）当落款靠右。一坨字（逗号隔开的、没分隔符但带单位的、单空格交替的）先拆成一行一行。
- **不做**：字体、字号、颜色自定义；表格、求和。那是渡表僧和 Excel 的事。
- **版式 9 个**：默认「便签」学锤子便签的长相（纸感底色、宽边距、标题加粗、底部日期；日期 0.3.2 起去掉了），不用它的名字、logo、素材，落款写誊抄僧。另 8 个：白纸（苹果备忘录那种）、信笺（衬线、横线）、牛皮纸（白标签贴标题）、夜读（深色、琥珀色数字）、杂志（衬线大标题、粗细两道线）、手账（点阵、纸胶带、荧光笔）、大字、公告（红题、双线、引导点、首行缩进）。挑四个留下是 Song 的事，对比图 `docs/版式候选.png`。
- **认手写**：不贴钥匙在浏览器里本地认，照抄渡表僧 v0.2.5 的认字 worker（一个字没改），模型从 `/pabiao/models/` 引，缓存名也用 `pabiao-ocr-1`：同一个手机用过渡表僧，这里不用再下 25 MB。每个字的把握低于 0.85 标黄。贴了钥匙借 Gemini 认两遍对答案，两遍不一样的字标黄、看不清的字写 □ 也标黄；谷歌出任何岔子都退回本地认，原话原样显示。钥匙、模型名、调用写法照录入僧网页版。
- **分享**：Web Share（带文件）弹手机分享面板；不支持的浏览器（微信里、电脑上）弹一层大图「长按存进相册」加「存图」按钮。图在改完字半秒后先画好放着，点分享时手里已经有图——iPhone 的 Safari 要求分享紧跟着点击，现画来不及会被拒。
- **固定比例装不下**：先把字整体缩一点（最多到 0.78），还装不下就按长图出，底下一句「字多，3:4 装不下，按长图出」。大字版在固定比例里上下居中。
- **第一次打开只下一个文件**：104 KB（gzip 后 38 KB）。思源宋体等用到衬线版式才挂样式表。

### 边做边比
三轮，记录在 `docs/对比/记录.md`。主要改掉的：标题和自动日期重复、全角标点被转半角、孤字、「时间：11月8日 8:00-17:00」被拆碎又被当成数字、称呼被当成分组标题、手账把编号换成方框、胶带假、牛皮纸脏、手机分享按钮不通栏。

### 踩过的坑
- 网格布局里 `1fr` 的最小宽度会被画布的原始宽度撑开，手机上整页横着滚：改 `minmax(0, 1fr)`。
- `wrap()` 把全角转半角用在了显示的字上，中文逗号变成了「,」。全角转半角只用来认数。
- 「11/1」「8:00」：数字前面紧挨着「/ - . :」再前面是数字的，不是「名字＋数字」。
- 画缩略图时用到「Noto Serif SC」，浏览器会自己去下字体分片，第一次打开多下了 680 KB：样式表改成用到衬线版式才挂。

### 还糙的地方（留给精加工）
- 手写认字：龙藏体那种行书的「件」左边一撇会被认成「1」（`12801件`），4 个错里标黄了 3 个。没做「数字后面多一个 1 再接单位」的纠错，怕误伤。
- 中文折行不懂词：「把数 / 据存好」这种会出现；只管了最后一行别剩一两个字。
- 拍照只拉正了有横线的纸；白纸上的字歪得厉害时不会拉。
- 9 个版式还没让 Song 挑；字体、留白在真手机（苹果、安卓各一台）上没看过，只在 Edge 模拟的 iPhone 尺寸里看过。
- 微信内置浏览器里不能直接调分享面板，只能长按存图；没在真微信里试。
- 没上线：公开仓库、Pages、总舵卡片留给聊天窗口。

## 0.3.0：写字的纸就是成品（2026-11-02，施工单 013 第三版）

Song 的原话（11:06）：「点模版上面出现的是文字排版，不是图片，但是和下面图片的风格完全一样……默认是第一个样板风格，也就是锤子便签那个。」11:10：「可以分享和保存相册两个选择。」

### 拍的板
- **纸用 canvas 画，跟分享的图走同一段 `paint()`**。单子给了两条路：一条是网页排版加上可以改的字，另一条是把网页拍成图。这两条都选不上：网页排出来的字和 canvas 画出来的字，字形边缘、折行不会一模一样；拍网页在 iPhone 上要异步嵌字体，会丢掉点按的那一下。纸和图既然是同一段代码按同样的位置画的，就天然一模一样。单子的顺序是「准」排第一，所以选它。
- **打字落在一个看不见的 textarea 里**（CodeMirror 5、Google Docs 也是这个办法）。它跟着光标走，宽 1 像素、透明，字号 16（iPhone 上小于 16 会自己放大页面）。拼音、删字、撤销、方向键、Ctrl+V 都是浏览器自己的。光标、选区、黄字画在纸上面一层，这一层不进图。
- **原文第几个字 ↔ 纸上哪个位置**：`layout()` 画的每一段字都带上原文的行号（`cid`）。`caretMap()` 一个字一个字对回原文。全角半角、大小写算同一个字，标点和标点也算对上。纸上自己加的字（「：」「—— 」、公告标题字间的空格）跳过；原文里没画出来的字（名字和数字中间的空格、【】、换成圆点的「-」）也跳过。点纸就找最近的一行，再找这行里最近的缝。
- **正在写的那一行先不落定**（`parse(text, title, hold)`）。光标进哪一行，就记下这时整张纸认成了什么样。在这行里打字时，别的行、标题、落款、固定比例的字号都照记下的样子不动；这行自己认得成原来那样就照原来排，认不成就按原样排成一行字。换行、光标挪到别的行、收起键盘，才整张重新落定。所以打「今日产量」不会打到一半突然放大，打「A线 12件」数字也不会半路飞到右边。
- **拼音组字时纸一点不动**：组字中途不重画，组到一半的拼音浮在光标那儿，带下划线，底色取纸上那一点的颜色。上屏以后才重画。
- **默认便签**：每次打开都从便签开始，上次写的字照旧留着，比例、格式照旧记着。
- **版式条固定在底下**，位置照苹果相册编辑照片时的滤镜排，在「保存相册」「分享」上面。缩略图的样子没改。手机键盘弹着时（屏幕下面被挡掉 120 像素以上）版式条让开，两个按钮贴着键盘上沿（0.3.1 起改成整条收起来，见下）。电脑上点版式，光标留在纸上。
- **「比例」「格式」收进右上角齿轮**。
- **两个按钮一样宽，「分享」实心放右边，「保存相册」浅蓝放左边**。苹果的规矩是一屏只放一个实心按钮，给最常用的那个，放在靠后的位置。对比图 `docs/对比/r4_界面_对R03R04.png`。
  - 保存相册：安卓、电脑直接下文件，冒一句「存好了，在「下载」里」。iPhone 的网页没法自己把图存进相册（`<a download>` 存进的是「文件」App），所以弹系统面板，面板里点「存储图像」（英文系统是 Save Image）。
  - 分享：弹系统分享面板。电脑上弹不出来，就把图复制进剪贴板，冒一句「图已复制，去聊天窗口粘贴」。别的弹不出来的情况，退到大图页长按存。
  - 微信里（UA 带 MicroMessenger）：两个按钮都弹大图页，写「长按图片，选「保存图片」或「发送给朋友」」。大图用 data 地址，存图按钮藏掉（微信里下载不了）。
- **加了「粘贴」按钮**（纸上没字时才露出来）：纸是 canvas，iPhone 上长按纸已经被「这行当标题」占了，拿不到系统的「粘贴」菜单。按钮用 `navigator.clipboard.readText()`，iPhone 会先冒一个「粘贴」小泡让你点。电脑上照样 Ctrl+V。
- **提示行**：纸下面小字一行「点哪改哪；长按一行，这行当标题。」

### 踩过的坑
- **纸和图对不上**，差在标题那几个大字的边缘。原因是挂在页面上的 canvas 写字时会沾上页面的样式（body 设了 `letter-spacing: -.01em`），没挂上的 canvas 不沾。改法：纸也先画在一张没挂上的画布上，再原样贴过去（`paint()` 开头）。两边的画布也都要 CPU 画（`willReadFrequently`）。
- **纸纹会跟着字数闪**：0.2.0 的噪点按整张纸的高度撒，多打一行，整张纸的纹理就全换了。改成按 128 高一块一块撒，每块有固定的种子，纸变长只是往下多撒几块。夜读的光晕半径也封顶在 520。9 个版式的长相统计上跟原来一样。
- **纹理每次重画太慢**：先画在备用画布上，按版式、高度、倍数缓存。纸和图贴的是同一份。
- **行尾打的空格光标差 1.8 像素**：Chrome 会在汉字和字母数字之间自动加一点空，单独量一个空格的宽度时算不进去。改成连着前面的字一起量。

### 还糙的地方
- 手指拖着选一段字没做（手指拖是滚页面，长按是当标题），只有点黄字整段选中、电脑上鼠标拖选、双击选一个词。iPhone 系统的选字把手、放大镜都没有。
- iPhone 上透明 textarea 弹键盘、拼音、联想词、空格键拖光标这些，只在 Edge 模拟里测过，没在真 iPhone 上试。
- 单子说的字体清单（思源黑体、思源宋体、霞鹜文楷、朱雀仿宋、Inter）：0.2.0 的代码里只有系统黑体（苹方 / 思源黑体）和思源宋体，没有后三个。单子写的是「别的都不动」，所以没加。

## 0.3.1：键盘弹着时底下那条整条收起来（2026-11-02）

Song 12:10 在 iPhone 上打字，截图圈住键盘上面那两个按钮：「输入法弹出这个去掉」。两个按钮贴在键盘上沿，正好压住正在写的那几行（截图里光标那行下面两行被按钮盖住）。

- **改了啥。** 手机键盘弹着时，底下那条（版式、「保存相册」「分享」）整条收起来（`visibility: hidden`，占的地方不变，页面不跳）。点键盘上的 ✓ 收键盘，它就回来。不再把按钮挪到键盘上面。
- **怎么认键盘弹着。** 正在写字，且看得见的高度（`visualViewport.height`）比整屏矮了 120 像素以上。整屏高度拿「没在写字时的 `innerHeight`」和现在的 `innerHeight` 取大的：iPhone、安卓 Chrome 弹键盘只缩看得见的那块，整页不缩；有的手机浏览器（安卓上一些套壳的）连整页一起缩，拿写字前记的高度比照样认得出。原来那套算法减了 `offsetTop`：iPhone 把页面往上推时会算成「没挡住」，按钮正好冒在键盘上面，这回不减了。
- **代价。** 打完字要先点 ✓ 收键盘，再点「分享」：打字 → 分享从 1 下变 2 下，拍照改黄字 → 分享从 3 下变 4 下。换版式本来就要先收键盘（0.3.0 起键盘弹着时版式条就让开了），不变。
- **测。** `tests/run_phone.py` 加 K：假键盘（focus 时把 `visualViewport.height` 改矮 336、发 resize），没写字时那条在、键盘弹着收起来、收键盘又出来，打字 → ✓ → 分享 2 下。A、B、D～I 照旧过（模拟浏览器里没键盘，那条一直在）。C、J 要本地认字模型，云端这边起不来，没跑；这回没碰认字。
- **还没在真 iPhone 上试**，等 Song 在手机上看。

- **字收进一处。** 界面上所有的字搬进 `strings.js`，英文、中文各 85 个键，一一对应；动态的字是函数，两套参数一样。页面上的静态字用 `data-s`（无障碍名 `data-s-aria`、占位字 `data-s-ph`、图片说明 `data-s-alt`）标上，开门和换语言时一起填。原来散在 `index.html` 里的 60 多处中文（按钮、提示、出错、版式名、空纸上的提示字、落款、存图文件名、示例字、认字 Worker 里的两句报错）一处不剩；留在代码里的中文只有认结构用的正则（合计、件、星期……）和发给 Gemini 的抄字指令（不是给人看的）。为什么单出一个文件、不塞回 `index.html`：单子写的是 strings 文件，另外八尊也是这么放的，清单导出直接读它。代价是第一次打开多一个请求：2 个文件 142 KB（本机不压缩），原来 1 个 128 KB；`strings.js?v=0.3.4` 带版本号，免得新页面配旧字。
- **默认英文，右上角 EN / 中文。** 选过就记在 `tengchao.lang`，读写都包 try/catch；不看浏览器语言（测过：浏览器设成 zh-CN、没选过，打开是英文）。语言在 `<head>` 里一个小脚本先定下来：`<html lang>`、`<title>`、meta description、存到 iPhone 桌面的名字第一帧就对，英文字体栈也第一帧就用上，不闪中文。换语言时写的字、版式、黄字都不动，版式名、纸上的提示字、落款、缩略图一起换。
