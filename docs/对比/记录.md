对比图脚本：`tests/compare.py <轮次>`，每个版式出两段示范文字（「产量」统计、「通知」），右边并排放它对标的参照。图在本机 `docs/对比/`（参照是别人的作品，对比图不进仓库），文件名 `<轮次>_<版式>_对<参照>.png`。九宫格：`tests/sheet.py`。

| 版式 | 对标参照 | 学它哪一点 |
|---|---|---|
| 便签（默认） | R01 Things 3 | 层次：大标题、灰正文、分组标题强调色加细线、行距宽 |
| 白纸 | R03 iPad 备忘录 | 很粗的短标题、上面小灰日期 |
| 信笺 | R06 TDC 公告 | 衬线长文，靠字重分层 |

| 大字 | R04 ADA 页面 | 大字号、大留白 |

## r0（第一版，2026-11-01 晚）
九宫格：`r0_九宫格.png`、`r0_通知_九宫格.png`。输在哪：
1. 标题已经写了「11月1日」，上面又自动印一行「2026年11月1日 星期日」，重复。参照里日期只出现一次。
2. 正文中文逗号被转成了半角「,」（全角转半角用错了地方）。
3. 正文最后一行只剩一两个字；杂志版标题折出一个「修」孤字。
4. **通知那段全乱**：「时间：11月8日 8:00-17:00」被拆成「时间 11 / 月 8 / 日 8 / :00…」——「一坨字拆行」的规则太松；拆对以后又被当成「名字＋数字」，数字是钟点里的「00」。
5. 通知开头「各车间：」是称呼，被当成分组标题染了强调色。
6. 手账版把「1. 2. 3.」换成了方框，编号丢了。

## r1（改了上面 6 条）
- 标题、落款里有日期，版式就不自动印日期。
- 只把全角字母数字转半角，中文标点原样留。
- 正文、清单、键值折行：最后一行不到 3 个字就收窄一点重折（行数不许变多）；标题折行用均分（行数不变下收到最窄）。
- 一坨字拆行：有冒号或钟点不拆；没分隔符的拆法每段必须带常见单位、名字至少两个字、不以年月日钟点开头结尾。冒号前紧挨数字的（钟点）不算「名字＋数字」的分隔；「短键：值」而值不是单纯的数，按键值排。
- 正文第一行以冒号结尾、下面接正文的，当称呼排：正常字、冒号保留、公告里也不缩进。
- 方框只给原来就是圆点、方框的清单。

对比图 `r1_*.png` 输在哪（跟参照比）：
- 便签、白纸、信笺、夜读、杂志、大字、公告：层次（标题 / 正文 / 数字 / 单位 / 日期）跟参照一个路数，不输。
- 手账：纸胶带画成了条纹贴图，看着假（Bear 那种干净的强调色没有这个毛病）。
- 牛皮纸：颜色偏橙发闷，跟 Chikaku 的暖色比脏。
