# 谁在什么时候用誊抄僧

施工单 012 开工第一件事。后面每个设计决定都要回答：省了这个人哪一步，让哪一眼更舒服。答不上来的功能不加。

## 三个时刻

**1. 组长在群里催数。** 下午四点，组长在微信群里发「各线今天产量报一下」。车间的人手边是一张手写的计数纸，或者手机备忘录里一行「A线早班12件 B线早班9件 C线中班15……」。他要在一分钟之内发出去，发出去的东西要让组长一眼看清谁多谁少、加起来对不对。
- 痛：手写的纸拍出来歪歪扭扭、阴影一片，组长要放大了猜；打字发出去是一坨，数字东一个西一个，没人愿意对。
- 要的：数字竖着对成一列。名字靠左，数靠右，小数点对齐，单位跟在后面。不要表格线，表格线在手机上显得像报表，压人。

**2. 要发一条通知。** 「明天上午 8 点到 12 点停电检修，各车间提前存好数据，有问题找设备科。」打字发群里会被刷下去；做成图片能被看见，可是没人会为一条通知去开 Word。
- 痛：一段话里的时间、地点、找谁混在一起，读的人要自己挑。
- 要的：标题自己变大变粗；「时间：」「地点：」这类行，冒号对齐，后面的字齐头；落款和日期靠右。

**3. 列个清单。** 采购单、交接班要做的事、要带的东西。手写在纸上，或者备忘录里一条一条。
- 痛：编号 1 到 12，到 10 以后序号宽了，整列歪掉；一条写长了折到下一行，顶格折下去，跟下一条分不清。
- 要的：序号右对齐，折行缩进到正文开头。

## 他手上有什么、没什么

- 有：手机（多半是安卓，一部分 iPhone），微信，一张纸或者一段字。
- 没有：时间。没有耐心挑模板、调字号。不会去装一个 App。
- 网络：车间里信号一般；第一次打开以后，能离线用最好。

## 由此定下的规矩（每条都说得出省了哪一步）

| 设计 | 省了哪一步 / 哪一眼更舒服 |
|---|---|
| 打开就是写字框，光标已经在里面 | 省「新建」那一下 |
| 不选版式也能直接「分享」，默认就好看 | 省「挑模板」。打字到发出去只点 1 下 |
| 拍照直接调相机，认完字直接进写字框 | 拍照到发出去 2 下：拍、分享 |
| 自己认标题、认「名字＋数字」、认清单、认「时间：」这类行 | 省「设格式」，这一步人永远懒得做 |
| 数字对成一列，小数点对齐 | 组长一眼比大小、核加总，不用逐行找数 |
| 拿不准的字标黄，点一下就选中、直接改 | 省「通篇校对」，只看黄的 |
| 改字的地方就是写字框本身，不另开一页 | 省「来回切」 |
| 分享走手机自带的分享面板（存相册、发微信都在里面） | 省「先存相册再去微信里找」 |
| 版式在预览下面横着排，点一下预览立刻变 | 想换样子只要 1 下，不用进设置 |
| 图按 3 倍屏画，长短跟着字走 | 放大不糊；不留一大截空白 |
| 不做：字体、字号、颜色的自定义 | 他不会用，多一个选项多一处难看的可能 |
| 不做：表格、公式、求和 | 那是渡表僧和 Excel 的事，这里只管「看着舒服」 |
